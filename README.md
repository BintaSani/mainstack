# Mainstack Dashboard

A React + TypeScript frontend project that displays user, wallet, and transaction data from the Mainstack API. The app follows the provided Figma design with attention to detail, responsive layouts, and interactive UI components.

## Features

- Fetches data from:
  - `/user` – user profile
  - `/wallet` – wallet balance
  - `/transactions` – transaction history
- Responsive Navbar and Sidebar
- Transaction filtering and export
- Custom date range picker
- Unit tests with Jest + React Testing Library

## Tech Stack

- **React (Vite) + TypeScript**
- **Tailwind CSS** for styling
- **React Query** for API state management
- **React Router** for navigation
- **Jest + RTL** for testing

## Project Structure

- `src/shared` – reusable logic (hooks, components, layouts, services, types)
- `src/features` – feature-based components (transactions, filters, charts, ledger)
- `src/components/ui` – base UI components (buttons, cards, inputs)
- `src/_tests_` – unit and integration tests

## Getting Started

```bash
npm install
npm run dev
npx vitest
```
